# Amazon-Retail-Intelligence-
Power BI analysis of 120K Amazon.in orders (31 Mar–29 Jun 2022), generating INR 71.67M gross revenue across 111K units sold. Set and Kurta drive 77% of sales, while M, L, and XL lead size demand. Tracks fulfilment, courier status, and cancellations (14.3%), highlighting an 18.5% revenue dip from April to June and action steps.
